## User story

As **Riley**, I want **a short tournament wrap in the diary** so **I know what to work on at the range**.

## Acceptance criteria

1. When committee **closes** an event, enrolled golfers receive a **diary context note** (format total, vs field median if available, biggest leak holes) — **no automatic Vertex call** unless the player sends a follow-up in the composer.
2. Note links to **Range** drill suggestions by tag (putting, approach) per Roadmap A2 — prescription detail in shard when built.
3. Personal rounds unaffected.
